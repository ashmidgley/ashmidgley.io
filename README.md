# ashmidgley.io

Personal portfolio site for Ash Midgley, built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Overview

This project powers [ashmidgley.io](https://ashmidgley.io), a software engineering portfolio presented as a terminal.
Visitors run commands (or tap the suggestion chips) to print each section:

- `whoami` - intro (runs automatically on load)
- `experience` - previous work experience
- `work` - selected projects
- `stack` - technologies, by how often they've been used
- `contact` - email and social links
- `help`, `ls`, `clear`

### Easter eggs

`ls -a` reveals two hidden directories that switch the whole site into another mode:

| Command | Opens |
| --- | --- |
| `cd .story` or `man ash` | `/lab/story`: the site as a scroll-driven story |
| `cd .canvas` or `startx` | `/lab/canvas`: the site as a desk of draggable cards |

`ls -a` also lists `.theme`: run `theme` to show or hide the background hover effect
switcher, or `theme <halo|lens|comet|sonar>` to pick one directly. Comet is the default.

Also try `sudo hire-ash`.

## Color Palette

Dark theme with a single green accent. Colors are applied as Tailwind arbitrary values (e.g. `text-[#00fd35]`) rather than theme tokens.

| Color | Value | Usage |
| --- | --- | --- |
| Background | `#111010` | Page background (`app/layout.tsx`) |
| Surface | `#171616` | Cards and tiles |
| Accent green | `#00fd35` | Eyebrow labels, card titles, links, quote borders, badge text/border |
| Deep green | `#006b35` | Badge background |
| White | `#ffffff` | Primary text, logo keys, header button |
| Black | `#000000` | Text on accent-green surfaces, logo key strokes |
| Border | `white/15` | Card borders (white at 15% opacity) |
| Body text | `slate-300` | Paragraph copy (Tailwind v4: `oklch(86.9% 0.022 252.894)`) |
| Muted text | `slate-400` | Dates and secondary links (Tailwind v4: `oklch(70.4% 0.04 256.788)`) |

## Tech Stack

- Next.js 16 (App Router, Turbopack)
- React 19
- TypeScript 6 (held below 7 until `typescript-eslint` supports it)
- Tailwind CSS 4 (CSS-first config in `app/globals.css`, no `tailwind.config.js`)
- Framer Motion
- Vercel Analytics
- ESLint 10 (`eslint-config-next`)
- Jest 30 + Testing Library

## Routes

- `/` - Terminal landing page
- `/lab/story`, `/lab/canvas` - Hidden modes launched from terminal easter eggs (noindex)
- `/lab/classic` - The previous single-scroll homepage, parked (noindex)
- `/robots.txt` - Generated by `app/robots.ts`
- `/sitemap.xml` - Generated by `app/sitemap.ts`

## Project Structure

```text
app/
  layout.tsx         # root layout: fonts, metadata, motion config, analytics
  page.tsx           # terminal homepage + JSON-LD
  lab/               # noindex pages, each with a "~ exit" link back to /
    story/  canvas/  classic/
  globals.css        # Tailwind import + base styles
  robots.ts          # /robots.txt
  sitemap.ts         # /sitemap.xml
lib/
  content.ts         # all site copy: profile, experience, projects, stack
components/
  Terminal.tsx       # the homepage shell: commands, boot sequence, easter eggs
  Header.tsx         # fixed logo + "Email me" button
  Nav.tsx, Footer.tsx  # classic page only
  Background.tsx     # dot grid + hidden variant switcher (?bg=halo|lens|comet|sonar)
  DotGrid.tsx        # interactive canvas dot grid and its variants
  PreviousExperience.tsx, SelectedWork.tsx, ProjectSummary.tsx, WorkWithMe.tsx  # classic page only
  Badge.tsx
  AKey.tsx, MKey.tsx, MKeyFlipped.tsx, BackArrow.tsx  # SVG graphics
  AnalyticsWrapper.tsx
  MotionProvider.tsx # honours prefers-reduced-motion for framer-motion
  lab/               # Story and Canvas modes + ExitLink
  __tests__/         # component tests
public/
  images/            # portfolio screenshots
  fonts/             # Sharp Grotesk local fonts
  og.jpg             # Open Graph image
  favicon / icons
```

## Getting Started

### Prerequisites

- Node.js 20.9+ (recommended: current active LTS)
- pnpm

### Install

```bash
pnpm install --frozen-lockfile
```

### Run locally

```bash
pnpm dev
```

Open `http://localhost:3000`.

## Available Scripts

- `pnpm dev` - Start local dev server
- `pnpm build` - Build for production
- `pnpm start` - Run production server
- `pnpm lint` - Run ESLint
- `pnpm test` - Run Jest in watch mode
- `pnpm test:ci` - Run Jest once (CI mode)
- `pnpm test:types` - Run TypeScript checks without emit

## Testing Notes

- `components/__tests__/Terminal.test.tsx` - commands, typo suggestions, easter egg navigation
- `components/__tests__/Background.test.tsx` - dot grid variant switcher
- `components/__tests__/PreviousExperience.test.tsx`
- `components/__tests__/SelectedWork.test.tsx`
- `components/__tests__/WorkWithMe.test.tsx`

Run all tests with:

```bash
pnpm test:ci
```

## Deployment

The project is configured for typical Next.js deployment (e.g. Vercel).  
`@vercel/analytics` is mounted via `components/AnalyticsWrapper.tsx`.
